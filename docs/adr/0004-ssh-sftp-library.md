# ADR-0004. SSH/SFTP Library

- Статус: Proposed
- Дата: 2026-11-21
- Джерело: цільова архітектура, частина 2 аудиту (артефакт від 21.11.2026)

## Контекст

Вимоги: SFTP, SCP, PTY, ключі, keyboard-interactive, ProxyJump, known_hosts.

## Розглянуті альтернативи

SSH.NET (MIT), Rebex (комерційна), обгортка над OpenSSH ssh.exe.

## Рішення

SSH.NET 2026.x. ProxyJump — через локальний forwarded port на bastion-з’єднанні; агент — Pageant/OpenSSH agent як окреме завдання після MVP `PROPOSED`.

## Наслідки

Власна реалізація known_hosts (формат OpenSSH, хешовані хости), власний діалог перевірки ключа.

## Ризики

Застарілі алгоритми на старих серверах; продуктивність SFTP на високій затримці (паралельні запити).

## План міграції

Нове.

## Перевірка (тести)

OpenSSH у контейнері: пароль/ключ, змінений ключ, обрив, Unicode, 10 ГБ файл, паралельні передачі.
