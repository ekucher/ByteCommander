# ADR-0005. Credential Storage

- Статус: Proposed
- Дата: 2026-11-21
- Джерело: цільова архітектура, частина 2 аудиту (артефакт від 21.11.2026)

## Рішення

Секрети лише у Windows Credential Manager (CRED_TYPE_GENERIC, target ByteCommander:<profileId>); профілі в JSON без секретів; ключові файли — лише шлях; паролі до ключів не зберігаються за замовчуванням `PROPOSED`.

## Розглянуті альтернативи

DPAPI-файл (для портативного режиму, прив’язаний до користувача), власне шифрування з майстер-паролем.

## Наслідки

Портативний режим на іншій машині вимагає повторного введення паролів — задокументувати.

## Ризики

Будь-який процес користувача може прочитати свої облікові дані — модель загроз Windows; не обіцяти більше.

## Перевірка (тести)

Секрет не з’являється в журналах, settings.json, експорті профілів (пошук рядка в усіх артефактах тесту).

## Примітка
