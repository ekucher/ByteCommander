# ADR-0006. Plugin Isolation

- Статус: Proposed
- Дата: 2026-11-21
- Джерело: цільова архітектура, частина 2 аудиту (артефакт від 21.11.2026)

## Контекст

.NET assembly у процесі не є пісочницею; AssemblyLoadContext дає вивантаження, але не безпеку.

## Рішення

Два рівні: «вбудовані/довірені» (підписані автором, у процесі, ALC) і «зовнішні» (окремий процес-хост, IPC через named pipes + StreamJsonRpc, обмежений набір дозволів у маніфесті) `PROPOSED`.

## Наслідки

Провайдери з високою пропускною здатністю — у процесі; переглядачі/команди сторонніх — поза процесом.

## Ризики

Вартість IPC; складність SDK. Тому SDK — після стабілізації Core.

## Перевірка (тести)

Збій плагіна не обвалює застосунок; невідповідність версії; відмова в дозволі.

## Примітка

У вихідному ADR не розписано: Розглянуті альтернативи, План міграції. Доповнити за шаблоном `0000-template.md` перед зміною статусу на Accepted.
