# ADR-0007. Archive Engine

- Статус: Proposed
- Дата: 2026-11-21
- Джерело: цільова архітектура, частина 2 аудиту (артефакт від 21.11.2026)

## Рішення

Читання й навігація через SharpCompress як ArchiveProvider (read-only); створення ZIP — наявний System.IO.Compression; 7z/RAR запис — не в MVP. Ліміти: записи, сумарний розмір, коефіцієнт, глибина вкладення, імена (zip-slip, ADS, зарезервовані) `PROPOSED`.

## Ризики

Модифікація архіву «на місці» = перебудова через тимчасовий файл (наявний WriteViaTemp).

## Перевірка (тести)

Corpus шкідливих архівів (path traversal, symlink, bomb, пошкоджені заголовки).

## Примітка

У вихідному ADR не розписано: Контекст, Розглянуті альтернативи, План міграції. Доповнити за шаблоном `0000-template.md` перед зміною статусу на Accepted.
