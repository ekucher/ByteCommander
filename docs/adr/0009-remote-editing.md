# ADR-0009. Remote Editing

- Статус: Proposed
- Дата: 2026-11-21
- Джерело: цільова архітектура, частина 2 аудиту (артефакт від 21.11.2026)

## Рішення

Завантаження у тимчасовий каталог сесії → редагування наявним редактором → збереження: перевірка, що віддалений файл не змінився (mtime/size, хеш якщо є) → запис у тимчасовий віддалений файл → атомарний rename (якщо можливість є) → збереження прав (chmod до вихідного режиму). Для критичних шляхів (/etc, /etc/pve) — підтвердження й показ diff перед записом `PROPOSED`.

## Ризики

/etc/pve — pmxcfs не підтримує частину операцій; rename у межах каталогу має працювати, але треба тест на реальному PVE `UNKNOWN`.

## Перевірка (тести)

Конфлікт одночасних змін, обрив під час запису, нестача місця, збереження режиму 600.

## Примітка

У вихідному ADR не розписано: Контекст, Розглянуті альтернативи, План міграції. Доповнити за шаблоном `0000-template.md` перед зміною статусу на Accepted.
