# ADR-0010. Windows Server Compatibility

- Статус: Proposed
- Дата: 2026-11-21
- Джерело: цільова архітектура, частина 2 аудиту (артефакт від 21.11.2026)

## Рішення

Одна збірка.NET 10. Офіційні статуси: Server 2016–2025 Desktop Experience — SUPPORTED після проходження тестової матриці; 2012/R2 — LEGACY (лише з ESU, без гарантій довгих шляхів); Server Core — віддалено через SMB/SSH/WinRM; окремого legacy-build немає `PROPOSED`.

## Перевірка (тести)

VM-матриця + ручний чекліст RDP/DPI/буфера обміну перед кожним мінорним релізом.

## Примітка

У вихідному ADR не розписано: Контекст, Розглянуті альтернативи, Ризики, План міграції. Доповнити за шаблоном `0000-template.md` перед зміною статусу на Accepted.
