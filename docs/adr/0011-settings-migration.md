# ADR-0011. Settings Migration

- Статус: Proposed
- Дата: 2026-11-21
- Джерело: цільова архітектура, частина 2 аудиту (артефакт від 21.11.2026)

## Рішення

SchemaVersion, атомарний запис,.bak перед міграцією, невідомі поля зберігаються, повідомлення при пошкодженні з варіантами «відновити з резервної копії / почати з типових» `PROPOSED`.

## Перевірка (тести)

Наявний тест сумісності `CONFIRMED` + пошкоджений файл, порожній файл, майбутня версія схеми.

## Примітка

У вихідному ADR не розписано: Контекст, Розглянуті альтернативи, Ризики, План міграції. Доповнити за шаблоном `0000-template.md` перед зміною статусу на Accepted.
