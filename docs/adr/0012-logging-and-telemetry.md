# ADR-0012. Logging & Telemetry

- Статус: Proposed
- Дата: 2026-11-21
- Джерело: цільова архітектура, частина 2 аудиту (артефакт від 21.11.2026)

## Рішення

Microsoft.Extensions.Logging + rolling file у %LOCALAPPDATA%\ByteCommander\logs (7 днів), рівні, кореляція за Id операції, редагування секретів (паролі, токени, user:pass@ в URL). Телеметрії в мережу немає (принцип роботи без інтернету); «Зібрати діагностику» — zip журналів за явною дією `PROPOSED`.

## Перевірка (тести)

Redactor unit-тести; журнал не містить секретів після сценаріїв SFTP.

## Примітка

У вихідному ADR не розписано: Контекст, Розглянуті альтернативи, Ризики, План міграції. Доповнити за шаблоном `0000-template.md` перед зміною статусу на Accepted.
