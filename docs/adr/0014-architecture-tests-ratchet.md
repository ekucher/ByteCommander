# ADR-0014. Архітектурні тести з ratchet-baseline

- Статус: Proposed
- Дата: 2026-11-21
- Зачіпає: CI, `tests/ByteCommander.ArchitectureTests`, `build/architecture-baseline.txt`

## Контекст
Правила з AGENTS.md і `docs/architecture/dependency-rules.md` без автоматичної перевірки не виконуються: майже весь код
пишуть AI-агенти, рев'ю не завжди є. У v0.3.0 вже є борг: 2 цикли файлів, 93 звернення до диска з UI-класів,
6 файлів понад 400 рядків, 5 статичних mutable-полів, 9 порожніх `catch`. Виправити все одним PR — це велике переписування.

## Розглянуті альтернативи
| Варіант | Плюси | Мінуси |
|---|---|---|
| A. Лише рев'ю | нуль інструментів | не масштабується, агенти не бачать правил |
| B. NetArchTest.Rules 1.3.2 | простий API | немає зручної перевірки циклів між зрізами |
| C. TngTech.ArchUnitNET 0.13.5 + тести за вихідним кодом + baseline | цикли (`BeFreeOfCycles`), залежності, власні правила | ще одна тестова залежність |
| D. NDepend | потужний | комерційний |
| E. Виправити весь борг до вмикання правил | чисто | великий одночасний рефакторинг |

## Рішення
C. Відомі порушення записано в `build/architecture-baseline.txt`. Тест падає, якщо з'явилося нове порушення
**або** якщо виправлене порушення ще лишилося в baseline. Baseline може лише зменшуватися.
Кожен прогін записує фактичний стан у `architecture-baseline.actual.txt` (артефакт CI).

## Наслідки
- Нові порушення блокуються одразу (після вмикання як required check), старі виправляються поступово (кроки G1–G5).
- Зміна baseline у PR видна в диффі; додавання рядків заборонене AGENTS.md.

## Ризики
| Ризик | Імовірність | Вплив | Пом'якшення |
|---|---|---|---|
| Хибні спрацьовування regex-правил (AR-10…AR-12) | середня | низький | уточнювати правило, а не вимикати |
| Розбіжність baseline з IL на першому прогоні | висока | низький | job неблокуючий, доки baseline не звірено з `actual` |

## План міграції
1. Цей PR: правила й baseline, job неблокуючий (`continue-on-error`).
2. Звірити baseline з `architecture-baseline.actual.txt` першого прогону.
3. Зробити job required (разом із K-9, branch protection).

## Перевірка
`dotnet test tests/ByteCommander.ArchitectureTests` у workflow `Architecture Gates`.
