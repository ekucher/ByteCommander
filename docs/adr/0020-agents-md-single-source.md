# ADR-0020. AGENTS.md — єдине джерело правил розробки

- Статус: Proposed
- Дата: 2026-11-21

## Контекст
Зміни в репозиторії роблять і люди, і автоматизовані помічники, часто паралельними гілками. Письмових правил
розробки в репозиторії не було, тож кожна задача відновлювала їх з опису.

## Розглянуті альтернативи
| Варіант | Плюси | Мінуси |
|---|---|---|
| A. Окремий файл правил для кожного інструмента | кожен інструмент читає «свій» файл | дублювання, розбіжності, назви інструментів у репозиторії |
| B. Правила в описі кожної задачі | гнучко | губляться, розходяться |
| C. Один `AGENTS.md` для всіх, без файлів під конкретні інструменти | одне джерело; відкритий формат | треба підтримувати актуальність |

## Рішення
C. `AGENTS.md` — єдиний нормативний файл правил. Зміни в ньому — лише через PR з погодженням власника.
Правила, які можна перевірити автоматично, дублюються в architecture tests (ADR-0014), а не лише в тексті.

## Наслідки
Шаблон PR відображає розділ 5 AGENTS.md; baseline-файли можна лише скорочувати.
