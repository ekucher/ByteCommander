# ADR-0020. Правила для AI-агентів як частина архітектури

- Статус: Proposed
- Дата: 2026-11-21

## Контекст
20 з 23 комітів v0.3.0 зроблено за участю AI-агентів, частина — паралельними помічниками у worktree.
Письмових правил для агентів у репозиторії не було, тож кожна сесія відновлювала їх з опису задачі.

## Розглянуті альтернативи
| Варіант | Плюси | Мінуси |
|---|---|---|
| A. Лише CLAUDE.md | читає Claude Code | інші агенти не читають; дублювання |
| B. Правила в описі кожної задачі | гнучко | губляться, розходяться |
| C. AGENTS.md — нормативне джерело; CLAUDE.md імпортує його (`@AGENTS.md`) і додає лише специфіку Claude | одне джерело для всіх агентів і людей | треба підтримувати актуальність |

## Рішення
C. Зміни AGENTS.md і CLAUDE.md — лише через PR з погодженням власника. Правила, які можна перевірити автоматично,
дублюються в architecture tests (ADR-0014), а не лише в тексті.

## Наслідки
Шаблон PR відображає розділ 5 AGENTS.md; baseline-файли агенти можуть лише скорочувати.
